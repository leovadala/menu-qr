# Menú QR

Sitio web estático de cinco páginas, optimizado para celulares y listo para publicar en GitHub Pages.

## Publicar en GitHub Pages

1. Crear un repositorio nuevo en GitHub.
2. Subir todo el contenido de esta carpeta a la raíz del repositorio.
3. Abrir **Settings → Pages**.
4. En **Build and deployment**, elegir **Deploy from a branch**.
5. Seleccionar la rama **main**, carpeta **/(root)** y guardar.
6. Usar la URL publicada por GitHub para generar el código QR.

No requiere instalación, compilación ni servidor propio.
